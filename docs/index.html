Файлы из облака, которое перестало их отдавать

Drydock описывает коллекцию на Яндекс.Диске, забирает то, что облако ещё отдаёт, сверяет хеши и пакует спасённое в архивы. Написан для случая, когда каталог цел, а файлы не скачиваются: клиент синхронизации видит, что файла нет локально, и получает ту же ошибку.

Файлы то отдаются, то нет — часть возвращается через дни. Поэтому программу имеет смысл держать запущенной подольше или возвращаться к ней в другие дни. Сделана под свою коллекцию: в первый день вытащила половину, сейчас — почти 98%.

Windows, Python 3.12+ (или готовый .exe), MIT.

Files from a cloud that stopped serving them

Drydock inventories a Yandex.Disk collection, takes whatever the cloud still serves, verifies hashes and packs the rescued files into archives. It is written for the case where the catalogue is intact but the files do not download: a sync client sees the file missing locally and gets the same error.

Files come and go — some come back days later. That is why the program is worth leaving running for a while, or starting again on other days. It was built for a real collection: half of it on the first day, almost 98% now.

Windows, Python 3.12+ (or the ready-made .exe), MIT.

Ethereum, BNB Chain and Polygon share one address — the network is chosen when you send, and it has to be the right one. USDT and USDC are cheaper on TRC-20 and TON: fees are cents. On Ethereum the fee can eat half the amount. Lightning is for small sums: seconds to arrive, near-zero fee. The name@domain form is understood by any Lightning wallet.

What it does

  • Inventoryrecords name, size, hashes and place in the tree — including files that can no longer be downloaded
  • Probechecks availability without downloading: first and last byte
  • Loopdownloads everything served and re-checks the rest until stopped
  • Archive3.9 / 1.9 GB volumes or a single file, verified after packing
  • Deletefrees the cloud with what is already verified; three strictness levels
  • Healthshows why it fails: reasons, nodes, jobs
  • Exportwrites the inventory to CSV or JSON — with hashes and state
