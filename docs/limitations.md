# Ограничения

[← README](../README.md) · **Русский** · [English](limitations.en.md)

## Не синхронизация

Обратной записи в облако нет. Программа только читает и удаляет — по вашему
решению. Если нужно держать две копии в согласии, это другой инструмент.

## Не вернёт то, чего облако уже не отдаёт

Если сервер отвечает `404`, файла нет. Останется запись в описи: имя,
размер, хеш, место в дереве — по ним можно искать копию в другом месте, но
скачать нечего.

## Токен привязан к машине

Хранилище секретов у каждой системы своё: в Windows это DPAPI (ключ держит
система и привязывает к учётной записи), в macOS — связка ключей, в Linux —
libsecret. Если службы секретов в Linux нет, остаётся файл с правами 0600
без шифрования — интерфейс так и пишет, без обещаний. Перенести хранилище
на другую машину нельзя; впрочем, войти заново дешевле, чем возить секрет.

## Нужен 7-Zip

Архив делает внешний 7-Zip: в Windows — установщик с 7-zip.org, в Linux —
пакет `p7zip-full`, в macOS — `brew install sevenzip`. Программа не таскает
его с собой, а без него опись, проба и выгрузка работают как обычно —
недоступен только шаг «Архив».

## Ярлык делается по-разному

`tools/make_shortcut.py` на Windows создаёт `.lnk`, на Linux — запись в
меню, на macOS — `.command` в `~/Applications`. Права администратора нигде
не нужны.

## Не заменяет резервную копию

Это спасательная операция: забрать то, что ещё отдаётся. Регулярного
резервного копирования, версий файлов и отката здесь нет.

## Хранилище может не отдать крупный файл

Больные машины часто отдают первые мегабайты и обрываются на середине.
Проба видит такой файл как недоступный, выгрузка оставляет `.part` и
докачивает при следующей попытке. Если файл не отдаётся целиком никогда,
спасти его не получится — останется запись в описи.

## Удаление необратимо для программы

Файл уходит из облака без обратной операции в Drydock; по умолчанию корзина
Яндекса обходится ради освобождения квоты. Удаляются только проверенные файлы
или файлы, выбранные человеком вручную. Удаление по одному вердикту
`unavailable`/504 отключено: доступность плавает, и такой ответ не доказывает
безвозвратную потерю. Перед запуском всегда показывается, что уйдёт.

## Один экземпляр на базу

Второй сервер увидит первый и не тронет его задачи, но работать вдвоём на
одной базе не стоит: два обхода пишут в один чекпоинт, две выгрузки — в один
`.part`.

## Сообщения о ходе задач пока по-русски

Интерфейс переведён на шесть языков, но строки вида «круг 3: спасено 12»
формируются на сервере по-русски. Это следующая задача, а не забытая мелочь.
