# Сравнение

[← README](../README.md) · **Русский** · [English](comparison.en.md)

| | Drydock | Клиент синхронизации | rclone |
|---|---|---|---|
| Помнит файлы, которые уже не скачать | да, пишет в опись | нет | нет |
| Сверяет хеш до переименования | да | да | да, `check` |
| Сам возвращается к недоступному | да, круг за кругом | нет | вручную или по расписанию |
| Тома под Телеграм | да, 3.9 / 1.9 ГБ | нет | нет |
| Удаляет из облака по уровням | да: проверенная копия, архив или ручной выбор | нет | вручную |
| Окно вместо командной строки | да | да | нет |
| Переживает отказы хранилища | частично: `500`, обрыв | нет | частично |

## Когда что брать

- **Клиент синхронизации** — когда облако работает и нужно, чтобы файлы были
  в двух местах.
- **rclone** — когда нужен скрипт, расписание и перенос в другое облако.
- **Drydock** — когда облако уже не отдаёт: нужно знать, что там было,
  забрать то, что ещё отдаётся, и не потерять запись об остальном.
